likeness secrets <action> [arguments] [flags]

  get     whether a secret is set, and with --reveal its value
  grant   mint a restricted key that reads the named secrets
  init    create the vault station.json names, with its master key
  keys    every key in the vault, and what it may do
  list    the names this key can read
  remove  drop a secret
  revoke  drop a restricted key
  rotate  a new root key for every secret; every other key is dropped
  set     store a secret, its value read from a terminal or from stdin

global flags: --config PATH, --deterministic, --instance REF..., --json, --passphrase-env VAR, --source API..., --strict, --vault-key NAME
run `likeness help secrets <action>` for one action
