likeness sources <action> [arguments] [flags]

  add     add a connection to --source API, tagged --instance TAG; its token goes to the vault first
  list    every connection of the active profile: ref, source, base, account and secret name
  remove  remove a connection and its account; the vault keeps its token
  rename  give a connection a new ref, its account and its token with it
  test    check the named connections, or every one, as doctor does

global flags: --config PATH, --deterministic, --instance REF..., --json, --passphrase-env VAR, --source API..., --strict, --vault-key NAME
run `likeness help sources <action>` for one action
